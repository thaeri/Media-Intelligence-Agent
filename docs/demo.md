# Five-minute reproducible demo

This walkthrough uses only synthetic data. The core path requires Docker Desktop and PowerShell; it makes no paid LLM call and does not start Ollama.

## 1. Start PostgreSQL and the API

```powershell
Copy-Item .env.example .env
# Set a local-only POSTGRES_PASSWORD in .env.
docker compose up --build -d
docker compose ps
```

Wait until `postgres` and `api` are healthy and `migrate` has exited with code 0. The migration/seed job is intentionally separate from API startup, and PostgreSQL has no host port.

```powershell
Invoke-RestMethod http://localhost:5215/health
```

Expected output: `Healthy`.

## 2. Inspect media and deterministic title analytics

```powershell
$media = Invoke-RestMethod http://localhost:5215/api/media
$media | Select-Object id,title,genre,contentType

Invoke-RestMethod `
  http://localhost:5215/api/media/22222222-2222-2222-2222-222222222222/analytics
```

The catalog contains `Desert Heroes`, `City Stories`, and `Championship Night`. The analytics response preserves the public contract:

```json
{
  "id": "22222222-2222-2222-2222-222222222222",
  "title": "City Stories",
  "viewingSessions": 100,
  "completionRate": 60,
  "adExposureRate": 75
}
```

These figures are calculated from deterministic viewing events, not generated by an LLM.

## 3. Exercise campaign analytics and the structured agent

Enable the Development-only benchmark override. It points the existing SDK client at a local deterministic chat stub and is rejected in Production.

```powershell
docker compose -f compose.yaml -f compose.benchmark.yaml `
  --profile benchmark up -d --build postgres migrate api api-memory

$city = Invoke-RestMethod `
  http://localhost:5215/api/benchmark/campaigns/44444444-4444-4444-4444-444444444444/analytics
$city.metrics | Format-List
```

Expected City Stories Launch aggregates are 10 total impressions, 5 eligible impressions, reach 2, average frequency 2.5, and eligible coverage 50%. Desert Heroes Encore deterministically produces 10, 6, 2, 3.0, and 60% respectively. The benchmark route exists only when `Benchmark:Enabled=true` in Development.

Now exercise the unchanged agent contract:

```powershell
$body = @{ question = "Compare campaign eligible impressions." } |
  ConvertTo-Json
Invoke-RestMethod -Method Post `
  -Uri http://localhost:5215/api/agent/ask `
  -ContentType application/json -Body $body
```

The returned object still has one `answer` property. Its deterministic text contains the evidence-verified claims that City Stories Launch has 5 eligible impressions and Desert Heroes Encore has 6. Internally, this request performs an SDK LLM round, calls `compare_campaign_performance`, validates strict schema v1, binds claims to the tool result, and renders only verified claims.

Fail-closed behavior is also reproducible:

```powershell
$body = @{ question = "[failure] compare campaign eligible impressions" } |
  ConvertTo-Json
Invoke-RestMethod -Method Post `
  -Uri http://localhost:5215/api/agent/ask `
  -ContentType application/json -Body $body
```

Expected answer:

```text
Structured response verification failed. No unverified analytics were returned.
```

## 4. Verify consent-aware identity behavior

Identity metrics are intentionally exposed to the model only as aggregate tool evidence; there is no raw identity HTTP endpoint. Run the focused offline checks:

```powershell
dotnet test tests/MediaIntelligence.Tests/MediaIntelligence.Tests.csproj `
  -c Release --filter FullyQualifiedName~AudienceIdentityAnalyticsTests
```

They verify multi-device deduplication, separate audiences, default-deny consent, unknown and conflicting devices, frequency, and zero denominators. No device ID, audience ID, or identity mapping is returned by the agent tool. Metric definitions are in [audience-identity-metrics.md](audience-identity-metrics.md).

## 5. Build and verify the pgvector index

```powershell
docker compose --profile search run --rm index-media
docker compose --profile test run --rm integration-tests
```

The first command explicitly indexes the three synthetic titles with the deterministic development embedding provider. Re-running it is idempotent. The real PostgreSQL suite verifies migrations, seed parity, persistence, vector indexing, model/dimension compatibility, deterministic ties, and hybrid retrieval; the semantic query `family drama city` ranks `City Stories` first.

There is no standalone search HTTP route. In the product flow, `search_media_content` is an agent tool and emits aggregate media metadata only. This test path demonstrates the same search service without requiring an LLM. See [semantic-search.md](semantic-search.md).

## 6. Optional Grafana view

Start the opt-in observability overlay:

```powershell
docker compose -f compose.yaml -f compose.observability.yaml `
  --profile observability up -d --build
```

Open [http://localhost:3000](http://localhost:3000). The provisioned Media Intelligence dashboard shows API rate/latency, agent and LLM latency, tool duration/errors, and evidence failures. Prometheus metrics link to Tempo traces where exemplars are available. Prompts, responses, credentials, and pseudonymous identifiers are not telemetry attributes.

## Clean up

```powershell
docker compose -f compose.yaml -f compose.benchmark.yaml `
  -f compose.observability.yaml --profile benchmark --profile observability down
```

Add `-v` only when you intentionally want to delete the local PostgreSQL volume.

## Troubleshooting

- **Compose says `POSTGRES_PASSWORD` is missing:** create `.env` from `.env.example` and set a non-production local value.
- **Port 5215 or 3000 is busy:** set `API_PORT` or `GRAFANA_PORT` in `.env` before starting Compose.
- **Campaign benchmark route returns 404:** start with `compose.benchmark.yaml`; the route is disabled by default.
- **Agent tries localhost Ollama:** the benchmark override was not applied. The base stack deliberately contains no Ollama service.
- **PostgreSQL tests are skipped on the host:** use the Compose `integration-tests` service, which supplies the real connection string.
- **Search has no vectors:** run the explicit `index-media` job after migrations/seeding.
- **Dashboard is empty:** generate requests after the observability overlay is running and allow a few scrape intervals.
